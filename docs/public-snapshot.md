# Public snapshot scope

This repository is a curated public snapshot of an early-stage internal prototype.

The goal is to make the engineering work easy to review without publishing unnecessary historical scaffolding, experimental assets or any real school/student information.

## Included

- Prisma domain model
- authentication and role-based authorization
- class and temporary-substitute access logic
- lesson-plan services and curriculum relationships
- student support/adaptation models
- attachment storage/access controls
- reporting logic
- selected React client flows and API layer
- synthetic seed data and local PostgreSQL setup

## Intentionally trimmed

The original development folder also contains UI iterations, curriculum seed material and work-in-progress screens that add little value to a code review. The public frontend is therefore a smaller read-oriented portfolio UI around the same API/domain model.

This is why the repository should be read as an engineering snapshot, not as a claim that the product is production-ready.
